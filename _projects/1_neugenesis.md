NeuGenesis reads scientific model code in MATLAB, R, Python, Julia and NONMEM without running it, and ties each parameter to the line of code that sets it and the source it cites. When it can't place a value, it says so instead of guessing.

We evaluated our own first approach blind, under rules written before the results, and withdrew the part that didn't work. Co-founded in 2026; part of the Johns Hopkins Pava Center Spark Accelerator.
